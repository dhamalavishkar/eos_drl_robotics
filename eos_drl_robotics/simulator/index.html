Gap 1: Edge Compute Bottleneck

The Problem: 3D semantic SLAM (Voxblox/OctoMap) requires millions of voxel raycasts, lagging at 2–4 Hz on edge GPUs like Jetson Nano. High latency causes collisions with moving pedestrians.

Our Solution: A lightweight MobileNetV3 CNN directly outputs a compressed 64×64 2D BEV semantic grid in <15 ms (60+ Hz) at FP16, cleanly separating static walls from dynamic pedestrians.

OctoMap: 2–4 Hz (Fail) Ours: 60+ Hz (Real-Time) ✓
✅

Gap 2: Sparse Reward Collapse

The Problem: Standard DRL with only a terminal destination reward (+1.0) suffers vanishing gradients in large indoor spaces (needs >10⁷ episodes and gets stuck in concave rooms).

Our Solution: Potential-Based Waypoint Reward Shaping (Ng et al., 1999) using classical A* global waypoints. The agent receives monotonic +0.1 guidance along the safe corridor: R_t = +0.1·I(Δd > 0) − 1.0·I(col) + 1.0·I(goal)

Sparse: 10,000,000 steps Shaped: 100,000 steps ✓
